# Lacobriga Survival

A small survival city builder for the phone, set in Iron Age Lacobriga (today's Lagos, in the Algarve, Portugal).
Lead a handful of villagers through hot dry summers, storms and winters: gather food and firewood, build homes, and keep the town's one well from running dry.

**Play it:** https://sichdar.github.io/lacobriga-survival/

- Made for a phone held upright, played with one hand. It also works in a desktop browser.
- Portuguese and English.
- The game saves in your browser. On iPhone, add it to the home screen (Share → Add to Home Screen) so Safari keeps your save.

This is an early prototype (version 0.1); the balance is a first guess.
